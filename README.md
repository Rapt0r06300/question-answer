# Question Answer

Assistant iPhone-first pour les opportunités ZBD : Safari Autopilot pour les formulaires web autorisés et Earn Optimizer pour classer sondages, jeux et quests.

## iPhone

1. Utiliser Safari avec l'extension Userscripts.
2. Installer `dist/question-answer.user.js` (ou via GitHub Pages).
3. Depuis ZBD, transférer l'URL exacte du sondage vers Safari.
4. Appuyer sur **COMMENCER**.
5. **REPRENDRE LE CONTRÔLE** est le kill-switch permanent ; **CONTINUER** repart d'un scan frais.

Le profil et l'historique restent locaux. Les CAPTCHA/vérifications restent manuels. Les jeux et publicités récompensées restent dans les apps natives et exigent une action humaine.

Voir `docs/autopilot-ios.md`, `docs/earn-optimizer.md` et `docs/superpowers/specs/2026-10-04-earn-optimizer-design.md`.
