# JustPlay Timer

JustPlay est intégré à Earn Optimizer comme opportunité cyclique.

- délai initial : **5 minutes**, configurable car il s'agit d'un comportement observé et non d'une garantie contractuelle ;
- `READY` quand la prochaine vidéo est disponible ;
- `COOLDOWN` avec compte à rebours sinon ;
- `OUVRIR JUSTPLAY` effectue uniquement le handoff vers l'application ;
- `VIDÉO VUE` confirme manuellement une vidéo réellement terminée et redémarre le délai ;
- les gains et minutes actives enregistrés localement calculent le rendement observé ;
- JustPlay rejoint le classement global sondages / jeux ZBD / JustPlay.

Le module ne déclenche, ne regarde, ne ferme et ne valide aucune publicité automatiquement. Il ne contourne aucune protection antifraude.
