# Safari Autopilot sur iPhone

Aucun PC n'est requis. Question Answer agit uniquement dans les pages Safari autorisées.

- **COMMENCER** lance le scan/remplissage.
- **REPRENDRE LE CONTRÔLE** annule les actions en attente et met le runtime en pause.
- **CONTINUER** relance un scan frais de la page.
- **ARRÊTER** termine la session.

Depuis le WebView ZBD, ouvre l'URL exacte dans Safari, paramètres et fragment inclus. CAPTCHA, vérification, iframe inaccessible, question inconnue ou ambiguë rendent le contrôle à l'utilisateur. Le script ne contrôle pas l'interface globale iOS ni les apps natives.
